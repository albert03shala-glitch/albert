# Newsletter Feedback Log

Append-only log. Every entry here must be a **general, reusable rule**,
not a one-off fix to a specific sentence. `threads-newsletter-check` must
read this entire file before writing any draft and apply every rule.
Rules here override the general voice profile in `voice.md` if the two
ever conflict — this file is the more specific, more recently corrected
source of truth.

Newest entries at the bottom. Do not delete old entries even if a later
one refines them — leave a note instead, so the history of what's been
tried stays visible.

Format per entry:

```
## YYYY-MM-DD
- Rule: <the durable instruction>
- Why: <what draft/feedback prompted it>
```
